# 2026-08-24

- 排查剪贴板「设置 300MB 仍报 3MB 限制」：日志 `limit: 3145728` 是默认 3MB。
- 根因：客户端接收用本地 `ClipboardSize`（默认 3），不使用服务器下发的 CLSZ；桌面模式 core 未传 `--settings`。
- 已改：Client 收到 CLSZ 后更新接收上限；CoreProcess 传入 `--settings`；Config 不再把 clipboardSharingSize 写成 true/false。
- 用户用 GitHub release 安装包，不是本地构建。现象确认：Win 主机设 300 不够；Mac 切成主机也设 300 再切回客户端后才正常。说明客户端接收读的是本机 `server/clipboardSize`，默认 3MB。
- 超限还会断连：客户端 `ServerProxy` 把 `TransferState::Error` 当成协议错误并 `requestDisconnect`。已改为超限只 skip 分片、不断开。
